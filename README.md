# 🧠 Company Insights 360° — Data Analysis Project

A complete **end-to-end analytics project** integrating **Python, SQL, and Power BI** to deliver meaningful **HR, Sales, and Performance insights** for a simulated organization.

---

## 📊 Project Overview

This project demonstrates the complete data analysis lifecycle:

1. **Data Extraction & Storage** — CSV files and SQLite database
2. **Data Cleaning & Transformation** — Using Python and Pandas
3. **SQL Analysis** — Joins, aggregations, and KPI analysis
4. **Visualization** — Interactive Power BI dashboards
5. **Insights Generation** — HR analytics, sales trends, profitability, and performance insights

---

## 🧩 Tech Stack

* 🐍 **Python** — Pandas, Matplotlib, SQLite3
* 💾 **SQL** — SQLite
* 📊 **Power BI** — Dashboard development and visualization
* 🧮 **DAX** — Custom measures and KPI calculations
* 📓 **Jupyter Notebook** — Data analysis and workflow execution

---

## 📂 Project Workflow

### 1️⃣ Data Collection

The project uses multiple datasets containing information related to:

* Employees
* Departments
* Sales
* Revenue and Profit
* Employee Performance

---

### 2️⃣ Data Processing

Python and Pandas are used to:

* Load datasets
* Explore the data
* Clean and transform information
* Prepare data for analysis

---

### 3️⃣ SQL Analysis

The datasets are stored in a **SQLite database** and analyzed using SQL.

Key SQL operations include:

* `JOIN`
* `GROUP BY`
* `ORDER BY`
* Aggregate Functions
* KPI Calculations

---

### 4️⃣ Power BI Dashboard

The processed data is visualized using Power BI to create an interactive business dashboard.

The dashboard helps analyze:

* Employee performance
* Department performance
* Sales and profit
* Regional performance
* Profit trends
* Discount impact
